Frequently Asked Questions

Why does Google Antigravity not show a Context Window bar by default?

Unlike single-loop CLI tools, Antigravity splits work across Planning and Execution phases in Orchestrator mode, isolates subagent sessions via invoke_subagent, and lazy-loads skills and MCP schemas. Antigravity still writes exact per-turn token counts and compaction checkpoints to local session transcript.jsonl files, which Antigravity Context Monitor reads passively.

How does v2.0 track auto-compaction and step rewinds without false positives?

The analyzer distinguishes genuine Antigravity CHECKPOINT compaction records from Browser Session Checkpoints and rolls back step_index rewind/retry branches cleanly. It exposes both Compacts (with pre→post history) and Rewinds counters, adapts to observed compaction peaks (~500k on 1M, 840k on claude-1m_840k, 85% on 200k/128k), and fires configurable compaction warnings.

Is Antigravity Context Monitor safe for my account?

Yes. It operates strictly read-only on local transcript.jsonl files, makes zero network calls, never modifies API headers, prompts, or auth tokens, sanitizes ~/.antigravity-context-monitor.json, and enforces a strict 127.0.0.1 origin guard on all Electron IPC handlers.

Which models and Antigravity Desktop versions are supported?

Verified on Google Antigravity Desktop v2.34.0 with backwards-compatible multi-anchor hooks for v2.32.x–v2.33.x. Includes 36 built-in models across GPT-OSS (128k), Claude 5.5 (200k + dynamic 1M/840k), Gemini 4 Neon/Carbon/Hydrogen/Argon, Gemini 3.x, and Orchestrator (1M), plus automatic discovery of future models and inline custom ceiling overrides.
